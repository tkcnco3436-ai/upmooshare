# UI 화면 캡쳐 (개발 전달용)

마이페이지 관련 4개 화면의 반응형 + 버튼(모달/오버레이) 실행 상태 캡쳐 모음.

## 캡쳐 규칙
- **기본 화면**: `1920` / `1200` / `390` px 3폭
- **버튼 실행 상태(모달/오버레이)**: `1200` / `390` px 2폭
- 배율 2x (레티나), 파일명 규칙: `{페이지}__{폭}__{상태}.png`

## 폴더 / 상태 목록

### mypage/ (마이페이지 — 비로그인 헤더)
| 상태 | 설명 |
|---|---|
| 01-default | 기본 화면 (1920/1200/390) |
| 02-card-add | 결제수단 추가 모달(카드사 선택 스텝) |
| 03-delete-card | 결제수단 삭제 확인 모달 |
| 04-logout | 로그아웃 확인 모달 |
| 05-avatar-menu | 프로필 사진 변경 메뉴 |
| 06-crop | 프로필 사진 크롭 모달 (샘플 이미지 로드) |
| 07-info-tooltip | 인포 아이콘 툴팁 |

### mypage-login/ (마이페이지 — 로그인 헤더)
mypage와 동일 상태 세트 (01~07).

### edit/ (기본 정보 수정)
| 상태 | 설명 |
|---|---|
| 01-default | 기본 화면 (1920/1200/390) |
| 02-email-edit | 이메일 변경 오버레이 |
| 03-password-edit | 비밀번호 변경 오버레이 |
| 04-avatar-menu | 프로필 사진 변경 메뉴 |
| 05-crop | 프로필 사진 크롭 모달 |

### withdraw/ (회원 탈퇴)
| 상태 | 설명 |
|---|---|
| 01-default | 기본 화면 (1920/1200/390) |
| 02-confirm-active | 확인 문구("탈퇴하겠습니다") 입력 → 회원탈퇴 버튼 활성 |
| 03-logout | 로그아웃 확인 모달 |

## 비고
- 총 48장.
- 크롭 모달은 실제 파일 업로드가 필요해 `image/logo_slider01.png`를 샘플로 로드한 상태.
- 아바타 메뉴는 사진 보유 시에만 클릭으로 열려, 캡쳐 목적상 오버레이를 강제 표시한 상태.
- 캡쳐 대상 원본: `화면/mypage.html`, `mypage-login.html`, `edit.html`, `withdraw.html`.
