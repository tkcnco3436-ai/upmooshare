## 1. 오늘 바꾼 것

### 로그인 · 회원가입 · 회원가입 완료 · 아이디 찾기 · 비밀번호 찾기

- **화면을 좌우로 나눴습니다** — 왼쪽 입력창, 오른쪽 배경 애니메이션
- 회원가입은 **2단계로 쪼갰습니다** — 약관 동의 → 정보 입력
- 약관 전문은 팝업으로 띄웁니다
- 회원가입 완료 화면 가운데 완료 체크 표시를 넣었습니다
- 아이디 찾기에서 휴대폰 번호를 입력하면 `-` 가 자동으로 들어갑니다
- 비밀번호 찾기는 메일 보낸 뒤 안내 문구가 나오고 버튼이 "재발송"으로 바뀝니다

### 크레딧 및 구독관리

- **크레딧 버튼 우측으로 알림 아이콘을 옮겼습니다** (전체 화면에 같이 적용)
- **알림 아이콘을 누르면 알림 목록이 펼쳐집니다** — 알림 페이지로 바로 넘어가지 않습니다
- 화면 폭을 넓혀 크레딧·구독을 좌우 2단으로 배치했습니다
- 맨 위에 배경 애니메이션을 넣고 글자가 타이핑되게 했습니다
- 이용내역에 전체 / 적립 / 사용 버튼을 넣었습니다
- 더보기 버튼을 목록 밖 아래 가운데로 옮겼습니다
- 우측 상단 "크레딧 충전" 버튼을 뺐습니다 — 아래 "충전하기"와 겹쳐서
- 크레딧·구독 카드를 마이페이지와 똑같은 모양으로 통일했습니다

### 알림

- **알림 카드 배치를 바꿨습니다** — 위에 분류·시간, 아래에 열기·삭제
- 안 읽은 알림은 **제목이 빨간색**입니다 (기존 왼쪽 점 표시 없앰)
- 분류 배지 색을 회색 배경 + 검정 글씨로 통일했습니다
- **"푸시 켜기" 버튼을 토글 스위치로** 바꿨습니다 — 켜도 배너가 남아 상태가 보입니다
- 헤더 알림 아이콘을 누르면 나오는 목록도 같은 배치입니다

### 헤더 (전 화면 공통)

- 헤더 메뉴를 **2개 → 4개**로 (기능 · 요금안내 · 갤러리 · 공지사항)
- 크레딧 버튼 우측으로 알림 아이콘 이동 — 알림·크레딧 화면에서 확인 가능

## 4. 참고

**빈 화면·오류 화면 보는 방법** — 한 파일에 여러 상태를 같이 넣고 안 보이게 감춰 뒀습니다. HTML 에서 `hidden` 을 지우면 나옵니다.

```html
<!-- 확인하려면 hidden 을 제거한다 -->
<div class="empty" hidden>이용 내역이 없습니다.</div>
```

이 폴더에 담긴 것: 비밀번호 찾기의 **발송 완료 안내**, 알림 화면의 **받은 알림 없음**, 크레딧 화면의 **미구독 상태** · **이용내역 없음**.
